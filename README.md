# Meiyu Group Website

The official Meiyu Group website, built with Next.js and ready for Vercel.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Vercel Deployment

Import the repository into Vercel and use the **Next.js** framework preset.
Keep the root directory as `./`; Vercel will use `npm run build` automatically.
No environment variables are required for the current public website.

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: create the production Next.js build
- `npm start`: run the production build locally
